# AI Chatbot Using Java

## Project Description
This project is a Java-based AI Chatbot developed as part of the CodeAlpha Java Programming Internship. It provides interactive communication through a graphical user interface using Java Swing.

The chatbot uses basic Natural Language Processing (NLP) techniques and rule-based responses to understand user messages and answer frequently asked questions.

## Features
- Interactive chatbot conversation.
- Greeting and farewell responses.
- FAQ-based question answering.
- Basic NLP text cleaning and keyword recognition.
- Java Swing graphical user interface.
- Help button with example questions.
- Clear Chat functionality.
- Automatic conversation history saved in a text file.

## Technologies Used
- Java
- Java Swing
- Java AWT
- File Handling
- Basic Natural Language Processing
- Rule-Based Response System

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java files:

```bash
javac Main.java Chatbot.java ChatbotGUI.java
```

5. Run the application:

```bash
java Main
```
